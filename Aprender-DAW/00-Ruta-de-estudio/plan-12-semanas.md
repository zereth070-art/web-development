# Plan de 12 semanas

## Semana 1

- HTML semántico.
- Markdown.
- Git básico.
- Práctica: página personal.

## Semana 2

- CSS, flexbox y grid.
- Responsive design.
- Práctica: landing responsive.

## Semana 3

- JavaScript básico.
- Variables, condiciones, bucles y funciones.
- Práctica: calculadora.

## Semana 4

- DOM y eventos.
- Formularios.
- Práctica: lista de tareas.

## Semana 5

- Programación estructurada.
- Arrays y objetos.
- Práctica: gestor de alumnos.

## Semana 6

- SQL básico.
- SELECT, INSERT, UPDATE, DELETE.
- Práctica: base de datos de biblioteca.

## Semana 7

- Modelo relacional.
- Joins.
- Normalización.
- Práctica: diseño de tienda online.

## Semana 8

- Backend básico.
- Rutas y controladores.
- Práctica: API REST sencilla.

## Semana 9

- Conexión backend + base de datos.
- Validación.
- Errores.
- Práctica: CRUD completo.

## Semana 10

- Autenticación.
- Sesiones o tokens.
- Seguridad básica.
- Práctica: login y roles.

## Semana 11

- Despliegue.
- Variables de entorno.
- Logs.
- Práctica: publicar una app.

## Semana 12

- Proyecto final.
- Documentación.
- Portfolio.
- Revisión y mejoras.
