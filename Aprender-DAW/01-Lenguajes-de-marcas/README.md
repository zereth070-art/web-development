# Lenguajes de marcas

## Temas

- HTML5.
- CSS3.
- Markdown.
- XML y JSON.
- Accesibilidad.
- SEO básico.

## Prácticas

- Crear una página personal.
- Maquetar un artículo.

- Convertir información XML a JSON.

Saber construir páginas bien estructuradas, legibles, accesibles y adaptadas a distintos tamaños de pantalla.
