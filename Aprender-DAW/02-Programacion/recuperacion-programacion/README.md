# Recuperacion de Programacion

Objetivo: repasar fuerte lectura/escritura, colecciones, excepciones y POO avanzado, pero entrenando sobre todo logica, consistencia y velocidad.

Este bloque no esta pensado para leer mucho. Esta pensado para repetir el mismo ciclo hasta que salga solo:

1. Entender el problema.
2. Sacar datos de entrada y salida.
3. Elegir estructuras.
4. Separar responsabilidades.
5. Escribir una version pequena que funcione.
6. Probar casos normales y raros.
7. Mejorar nombres, excepciones y duplicacion.

## Rutina express de 7 dias

Dia 1: metodo + 3 ejercicios pequenos de colecciones.

Dia 2: lectura de CSV/TXT + validacion de lineas.

Dia 3: excepciones + reescribir codigo para que no reviente sin control.

Dia 4: herencia, clases abstractas e interfaces.

Dia 5: mini-gestor completo con ficheros, mapas y clases.

Dia 6: simulacro 1 cronometrado.

Dia 7: simulacro 2 cronometrado + repaso de fallos.

## Regla de oro

Si un ejercicio te bloquea, no empieces escribiendo codigo. Escribe antes estas cuatro lineas:

```text
Entrada:
Salida:
Datos que tengo que guardar:
Pasos:
```

Cuando esas cuatro lineas estan claras, el codigo suele salir bastante mas rapido.
