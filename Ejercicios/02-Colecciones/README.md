# 02 - Colecciones

Objetivo: practicar `ArrayList`, `HashMap` y conteos rapidos.

## Tareas

1. Guarda productos en un `HashMap<String, Producto>` usando el codigo.
2. Muestra los productos sin stock.
3. Calcula el valor total del inventario.
4. Vende unidades de un producto.
5. Comprueba si el producto existe antes de vender.

## Comandos

```powershell
javac -d bin src\*.java
java -cp bin App
```
