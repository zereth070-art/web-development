# 03 - Excepciones

Objetivo: practicar cuando lanzar y cuando capturar.

## Tareas

1. `leerEntero` debe lanzar `NumberFormatException` si el dato es invalido.
2. El `main` debe capturar los errores y mostrarlos ordenados.
3. `dividir` debe lanzar `IllegalArgumentException` si el divisor es 0.
4. Prueba casos correctos e incorrectos.

## Comandos

```powershell
javac -d bin src\App.java
java -cp bin App
```
