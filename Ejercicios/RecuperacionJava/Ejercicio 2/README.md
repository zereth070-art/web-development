# EJERCICIO — Gestión simple de tareas

## Crea un programa que:

Lea un archivo:

```text id="4yz6vl"
tareas.txt
```

Con contenido tipo:

```text id="0wnlmc"
Estudiar Java,PENDIENTE
Comprar pan,HECHO
Repasar XML,PENDIENTE
```

---

# El programa debe:

## 1.

Leer todas las tareas.

---

## 2.

Mostrar este menú:

```text id="65eif2"
1. Mostrar tareas
2. Mostrar pendientes
3. Contar tareas hechas
4. Salir
```

---

## 3.

Según la opción:

### Opción 1

Mostrar todas:

```text id="kxjwlt"
Estudiar Java - PENDIENTE
Comprar pan - HECHO
```

---

### Opción 2

Mostrar SOLO pendientes.

---

### Opción 3

Mostrar:

```text id="4c6r6x"
Tareas hechas: X
```

---

# REGLAS IMPORTANTES

## ❌ NO hagas:

* herencia,
* interfaces,
* abstracciones raras,
* gestores,
* parsers separados,
* arquitectura.

---

# SOLO:

* una clase `Tarea` si quieres,
* un `ArrayList`,
* lectura de archivo,
* menú con `switch`.

---

# Objetivo real del ejercicio

NO es hacerlo elegante.

Es:

## terminarlo entero.

---

# Tiempo recomendado

## 40-50 minutos máximo.
