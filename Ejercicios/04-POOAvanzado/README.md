# 04 - POO avanzado

Objetivo: practicar clase abstracta, herencia, polimorfismo y `HashMap`.

## Tareas

1. Revisa `Persona`, `Alumno`, `Profesor` y `Biblioteca`.
2. Anade un metodo para prestar libro a un alumno.
3. Haz que el alumno no pueda pedir mas de 3 libros.
4. Muestra todas las personas que pueden pedir libros.

## Comandos

```powershell
javac -d bin src\biblioteca\*.java
java -cp bin biblioteca.App
```
