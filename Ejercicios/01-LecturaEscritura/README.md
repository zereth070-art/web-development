# 01 - Lectura y escritura

Objetivo: leer ficheros, validar lineas y escribir resultados.

## Ejercicio A

Lee `alumnos.txt` con formato:

```text
nombre,dni,curso
```

Muestra solo los alumnos de curso mayor o igual que 2.

## Ejercicio B

Escribe en `salida.txt` los alumnos que pasan el filtro.

## Ejercicio C

Si una linea esta mal formada o el curso no es numero, ignorala y continua.

## Comandos

```powershell
javac -d bin src\App.java
java -cp bin App
```
